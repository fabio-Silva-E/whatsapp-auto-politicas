Política de Privacidade

Aplicativo: WhatsApp Auto · Última atualização: 26 de outubro de 2026

Antes de publicar: substitua os campos entre colchetes pelas informações reais do responsável. Confirme também que a aplicação não envia dados para nenhum servidor próprio.

1. Responsável

O responsável pelo aplicativo WhatsApp Auto é Fabio Silva Evangelista Dos Santos, com contato pelo e-mail fabio.e.s.santos@gmail.com. Endereço: Estado de São Paulo, Brasil.

2. Como o aplicativo funciona

O WhatsApp Auto automatiza ações no WhatsApp Web a partir do computador do usuário. Conforme a configuração atual informada pelo responsável, o aplicativo não mantém uma conta em servidor próprio nem envia dados para servidores controlados pelo desenvolvedor. As ações são realizadas na sessão do WhatsApp aberta pelo próprio usuário no navegador.

3. Dados tratados

Para executar as instruções do usuário, o aplicativo pode acessar localmente os arquivos escolhidos para envio (como imagens), os números ou conversas selecionados, e o texto das mensagens e legendas que o usuário informar. Esses dados são usados para realizar a automação solicitada. O aplicativo não deve ser usado com dados que o usuário não tenha autorização para tratar.

4. Envio pelo WhatsApp

Quando o usuário confirma o envio, as mensagens e arquivos são transmitidos pelo WhatsApp aos destinatários selecionados, através da sessão e dos serviços do WhatsApp/Meta. O tratamento desses dados pelo WhatsApp/Meta é regido pelos termos e políticas próprios dessas empresas. O responsável por este aplicativo não controla os sistemas nem as práticas de privacidade do WhatsApp ou da Meta.

5. Armazenamento e segurança

O aplicativo opera no computador do usuário. Arquivos escolhidos permanecem sujeitos às configurações e permissões desse computador; dados da sessão podem permanecer no perfil local do navegador usado pelo WhatsApp Web. Proteja o computador e não compartilhe seu perfil de navegador. O responsável não recebe cópia desses dados por meio de servidor próprio, conforme a configuração declarada acima.

6. Retenção e exclusão

O responsável não mantém uma base própria de mensagens ou arquivos enviados. Para remover arquivos, apague-os do computador. Para gerenciar ou excluir mensagens já enviadas, use os recursos disponíveis no WhatsApp; a exclusão pode não remover cópias já recebidas ou notificações dos destinatários. Para dúvidas ou solicitações relacionadas ao aplicativo, escreva para fabio.e.s.santos@gmail.com.

7. Direitos de titulares no Brasil

Nos termos da legislação brasileira de proteção de dados, incluindo a LGPD, titulares podem solicitar confirmação e acesso a dados pessoais tratados pelo responsável, correção, anonimização, bloqueio ou eliminação quando cabível, informações sobre o tratamento e demais direitos previstos em lei. Envie a solicitação para fabio.e.s.santos@gmail.com. Como o aplicativo opera localmente e o responsável não mantém uma base própria, talvez não seja possível localizar dados que permaneçam apenas no computador do usuário ou nos sistemas do WhatsApp/Meta; nesses casos, a solicitação deve ser dirigida ao respectivo serviço.

8. Crianças e adolescentes

O aplicativo não foi desenvolvido especificamente para crianças. O usuário deve respeitar as regras de idade aplicáveis ao WhatsApp e as leis locais.

9. Alterações e contato

Esta política pode ser atualizada quando o funcionamento do aplicativo mudar. A versão vigente será publicada nesta página. Contato: fabio.e.s.santos@gmail.com.
